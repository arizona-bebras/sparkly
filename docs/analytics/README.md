# Sparkly — аналитическая сводка

**Sparkly — платформа наблюдаемости для распределённых парков IoT-устройств.** Она создаётся для команд, которым нужно разбирать сбои контроллеров в эксплуатации: видеть, что происходило на конкретном устройстве, с какой сборкой прошивки оно работало и какие события предшествовали перезагрузке.

Без этой информации инженер часто получает жалобу или сигнал о недоступности, но не располагает контекстом для расследования. Ему приходится собирать логи вручную, пытаться воспроизвести сбой в лаборатории или запрашивать физический доступ к устройству. Sparkly помогает решить, что можно выяснить удалённо и когда действительно нужен выезд.

Основной сценарий — собрать метрики, логи и события запуска с помощью встраиваемого агента и предоставить инженеру данные для расследования. Первые пользователи — разработчики прошивок и команды эксплуатации; платформенные инженеры отвечают за интеграцию и развёртывание.

В репозитории реализованы сбор телеметрии агентом, регистрация тестового устройства на Linux, серверный приём и хранение сырых данных, отдельный модуль расшифровки телеметрии и интерфейсы для работы с парками, устройствами и инцидентами. Эти части ещё не дают завершённого сценария от полевого контроллера до разбора события в интерфейсе.
