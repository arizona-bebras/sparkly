# Источники данных о Sparkly

В этой папке хранятся исходные материалы, на которые следует опираться при подготовке и обновлении [аналитической сводки проекта](../README.md). Папка предназначена для источников; выводы и интерпретации остаются в аналитических документах.

- [Заявка на «Студенческий стартап»](Заявка%20на%20Студ%20стартап.md) — исходное описание проблемы, аудитории и продукта, рыночные гипотезы и параметры грантового сценария. Оценки из заявки не следует выдавать за подтверждённые результаты.

Текущий технический статус проверяйте по коду, конфигурации и тестам репозитория, а не по техническому описанию в заявке. При добавлении источника указывайте, какие данные из него можно брать и к какому периоду они относятся.
