# Analytics

Минимальный Go-проект аналитики без бизнес-логики. Планируется работа с ClickHouse, получение телеметрии и результатов символикации, gRPC-взаимодействие с backend и ML.

Запуск из этого каталога: `go run .`.
Проверка сборки: `go build -o bin/analytics .`.

`proto/service.proto` — пустая заготовка контракта.
